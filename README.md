# Shortest Known SAN Sequences

## About the Project

This project is an ongoing exploration of the shortest possible chess move sequences in Standard Algebraic Notation (SAN), starting from the standard chess starting position.

The goal is to determine the minimum number of plies required to reach a position in which a particular SAN move is legally available.

For every SAN move, the database records the shortest sequence length found so far, together with an example sequence that achieves that length.

## The Database

The Excel file contains the collected results, organized into separate worksheets.

Each entry contains:
- **SAN:** The chess move being investigated.
- **Shortest length:** The shortest known sequence length, measured in plies.
- **Example sequence:** One sequence of moves that reaches a position where the target SAN move is legal.

The database is continuously updated as shorter sequences are discovered.

## Finding Improvements

The database is publicly available so that anyone interested in chess, mathematics, or computational chess can explore the results.

You are encouraged to:
- Search for shorter sequences than those currently recorded.
- Independently verify existing sequences.
- Investigate interesting patterns in the minimum sequence lengths.
- Share any improvements or corrections.

If you discover a shorter sequence for an existing entry, contributions and suggestions are welcome.

## Important Notes

- All sequences start from the standard chess starting position.
- Lengths are measured in plies (one individual move by either White or Black).
- The recorded lengths represent the shortest sequences found so far, not necessarily mathematically proven minima.
- Only one example sequence is stored per entry, even when multiple sequences of the same minimum length exist.

## Contributions

The main purpose of sharing this database is to make the results accessible and invite independent exploration.

If you find an improvement, please share the SAN move, the new sequence, and its length.
